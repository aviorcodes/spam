# SMRAS Pro — Student Management & Result Analysis System

**Developed by: Shruti Jha**

A professional desktop application built with Python, Tkinter, NumPy, Pandas, Matplotlib, and SQLite.

---

## Features

- 🎓 **Student Management** — Add, edit, delete, search student records
- 📊 **Real-time Analytics** — Total, percentage, grade, rank, pass/fail
- 📈 **Visual Dashboards** — Bar charts, pie charts, topper banner
- 🔍 **Live Search** — Filter as you type
- 💾 **SQLite Storage** — Persistent local database
- 📤 **CSV Export** — One-click export of all records
- ⚙️ **Backup / Restore** — Save and reload the database
- 🎨 **Luxury UI** — Dark glassmorphic theme with gradient buttons

---

## Tech Stack

| Layer | Technology |
|---|---|
| GUI | Tkinter |
| Database | SQLite 3 |
| Analysis | NumPy + Pandas |
| Charts | Matplotlib |
| Language | Python 3.12+ |
